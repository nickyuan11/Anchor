# 定海神针 · 安装和使用说明（测试版）

谢谢帮忙测试！这个 App 会自动点掉开屏广告上的「跳过」按钮，抢在你误触「摇一摇」之前关掉广告。

现在是测试版，主要想请你帮一个忙：**遇到没被跳过的开屏广告时，点一下屏幕边上的 📷，然后把快照发给我。** 我会根据快照给那个 App 写专门的跳过规则。

> 不同手机、不同系统版本的菜单名字可能略有不同，下面的路径仅供参考。找不到的话截图问我就行。

## 一、安装

1. 我会通过微信发一个 **zip 压缩包**（微信会把直接发送的 `.apk` 改名成 `.apk.1`，导致无法安装，所以先压缩再发）。
2. 打开手机自带的 **「文件管理」**，进入 `Download/WeiXin` 文件夹（微信收到的文件都在这里），点开 zip 解压，再点解压出来的 `.apk` 安装。
   - 如果收到的是 `xxx.apk.1` 这样的文件：在同一个文件夹里长按它 → **重命名**，删掉末尾的 `.1`，再点它安装。
3. 如果提示「禁止安装未知来源应用」，按提示去设置里允许，然后返回继续安装。
3. 装好后桌面上会出现两个图标：
   - **定海神针**（深蓝色）：这就是 App 本体。
   - **广告测试**（橙色）：开发用的模拟广告，可以忽略，也可以拿来试试效果。

## 二、允许「受限制的设置」（Android 13 及以上需要）

不是从应用商店装的 App，系统默认不让开启无障碍服务，开关是灰色的、点不动。需要先解除限制：

1. 先按第三步去无障碍设置里点一次「定海神针 · 开屏跳过」，看到「受限制的设置」提示后点确定。
2. 打开 **设置 → 应用 → 应用管理 → 定海神针**（应用信息页）。
3. 点右上角的 **⋮**（三个点），选 **「允许受限制的设置」**，按提示验证身份。

鸿蒙 4.2 一般没有这个限制，开关能直接打开的话跳过这一步即可。

## 三、开启跳过服务

打开「定海神针」，主页显示红色的「跳过服务未开启」，点 **「去开启」**，会跳到系统的无障碍设置页：

- **红米 / 澎湃 OS**：在「已下载的应用」（或「更多已下载的服务」）里找到 **「定海神针 · 开屏跳过」** → 打开开关 → 确认。
- **华为 / 鸿蒙**：在 **设置 → 辅助功能 → 无障碍** 里找到 **「定海神针 · 开屏跳过」** → 打开开关 → 确认。

回到 App，主页变成 **「✅ 跳过服务运行中」** 就成功了。

> 服务只会读取屏幕内容来找「跳过」按钮，不收集、不上传任何数据。

## 四、防止被系统关掉（建议设置）

国产系统为了省电，可能会在后台把服务关掉，表现为主页又变回「未开启」。可以先做这些设置：

- **红米 / 澎湃 OS**：应用信息页 → **自启动** 打开；**省电策略** 选「无限制」；在最近任务里把「定海神针」下拉锁定。
- **华为 / 鸿蒙**：设置 → 应用和服务 → **应用启动管理** → 找到「定海神针」，改为「手动管理」，三个开关全打开；电池优化选「不允许」。

后续版本会在 App 里加一键跳转和图文引导。

## 五、抓快照（最需要你帮忙的部分）

1. 打开「定海神针」，在主页打开 **「显示快照按钮」**。屏幕右边会出现一个半透明的 **📷** 按钮，所有 App 里都能看到，按住可以拖到不碍事的位置。
2. 平时正常用手机。**遇到开屏广告没被自动跳过时，趁广告还在，点一下 📷**。看到「已保存快照」的提示就成功了。
3. 回到「定海神针」→ **「页面快照」**，找到刚才那条，点 **「分享」** → 发到微信给我。

小提示：
- 广告一般会停留几秒，看到广告直接点 📷 就来得及。来不及的话，退出那个 App 再打开一次。
- 广告被跳过了、但是**点错了地方**（比如点开了广告），也请抓一张快照告诉我。
- 快照会包含当时屏幕上的文字和截图，只保存在你手机上，只有你主动分享才会发出去。不放心的话分享前可以先看一眼。
- 不需要抓的时候，把「显示快照按钮」关掉即可。

## 六、设置和白名单

主页 →「设置」里可以：

- **通用关键词兜底**：对没有专属规则的 App，打开后 5 秒内自动点角落里的「跳过」。如果发现误点，可以先关掉它，再告诉我是哪个 App。
- **应用白名单**：加入白名单的 App 完全不处理。比如某个 App 被误点、或者你就是想看它的开屏，就把它加进去。
- **内置规则**：列出有专属规则的 App（目前是腾讯视频、爱奇艺），这些 App 跳得更准、更快。

跳过记录里每一条会标明是「通用兜底」还是「规则 xxx」。

## 七、遇到问题

- 主页显示「跳过服务未开启」：重新按第三步打开，并检查第四步的设置。
- 打开某个 App 时被误点了正常内容：请抓快照，或者截图告诉我是哪个 App、点到了哪里。
- 其他任何问题，截图发我就好。
