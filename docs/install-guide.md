# 定海神针 · 安装和使用说明（v1.0）

定海神针会自动点掉 App 开屏广告上的「跳过」按钮，抢在你误触「摇一摇」之前关掉广告。

- 不需要 root，只需要开启系统的「无障碍」服务。
- 只读取屏幕内容来寻找跳过按钮，不联网，不收集、不上传任何数据。
- 支持 Android 8.0 及以上，以及鸿蒙 4.x。不支持 iOS 和纯血鸿蒙（HarmonyOS NEXT / 5.0 及以上）。

> 不同手机、不同系统版本的菜单名字可能略有不同，下面的路径仅供参考。找不到的话截图问我就行。

## 一、安装

**如果装过测试版，请先卸载**：正式版和测试版的签名不同，不能直接覆盖安装。卸载后旧的跳过记录和快照会清空，无障碍服务和保活设置需要重新做一次。以后的正式版之间可以直接覆盖安装。

1. 我会通过微信发一个 **zip 压缩包**（微信会把直接发送的 `.apk` 改名成 `.apk.1`，导致无法安装，所以先压缩再发）。
2. 打开手机自带的 **「文件管理」**，进入 `Download/WeiXin` 文件夹（微信收到的文件都在这里），点开 zip 解压，再点解压出来的 `.apk` 安装。
   - 如果收到的是 `xxx.apk.1` 这样的文件：在同一个文件夹里长按它 → **重命名**，删掉末尾的 `.1`，再点它安装。
3. 如果提示「禁止安装未知来源应用」，按提示去设置里允许，然后返回继续安装。
4. 装好后桌面上会出现深蓝色的 **「定海神针」** 图标。

## 二、开启服务

第一次打开「定海神针」会自动进入 **「开启与保活引导」**（之后可以从主页再次进入）。按第一部分的步骤做，每一步后面会显示 ✅ 已完成 或 ❌ 未完成：

1. **允许受限制的设置**（仅 Android 13 及以上会显示）：不是从应用商店装的 App，系统默认不让开启无障碍服务，开关是灰色的或者点了提示「受限制的设置」。遇到这种情况：
   - 先在无障碍设置里点一次「定海神针 · 开屏跳过」，看到提示后点确定；
   - 再点引导里的「打开应用信息」，点右上角的 **⋮**，选 **「允许受限制的设置」**。
   - 开关能正常打开的话，跳过这一步。
2. **开启无障碍服务**：点「去开启」，在列表里找到 **「定海神针 · 开屏跳过」**，打开开关并确认。
   - 红米 / 澎湃 OS：一般在「已下载的应用」或「更多已下载的服务」里。
   - 华为 / 鸿蒙：设置 → 辅助功能 → 无障碍。
3. **允许忽略电池优化**：点「去允许」，在系统弹出的确认框里选「允许」。

回到主页，看到 **「✅ 跳过服务运行中」** 就成功了。

## 三、防止被系统关掉（请务必设置）

国产系统为了省电，可能会把服务关掉。引导页的第二部分会按你的手机品牌显示要做的设置，每一步有按钮跳到对应的系统页面，设好一项就勾选「已设置」。

- **红米 / 澎湃 OS**：允许自启动；省电策略改为「无限制」；在最近任务里锁定。
- **华为 / 鸿蒙**：应用启动管理改为「手动管理」，三个开关全部打开；在最近任务里锁定。
  - 鸿蒙 4.2 上点按钮可能提示「没找到对应页面，已打开应用信息页」。这时请手动进入：**设置 → 应用和服务 → 应用启动管理**，找到「定海神针」。

主页最上面的卡片会显示服务的运行情况：

- **✅ 跳过服务运行中 · 已连续运行 X 小时**：一切正常。
- **⚠️ 服务已开启，但没有在运行**：被系统关掉了。到无障碍设置里把开关关掉再重新打开，并检查上面的保活设置。
- **⚠️ 跳过服务未开启**：按第二节重新开启。

卡片下方的「最近启动时间」可以用来判断保活效果：锁屏放一晚后，启动时间还是前一天的，说明整晚没被关掉过。

## 四、日常使用

开启后不需要再管它。打开其他 App 时，开屏广告会被自动跳过。

- **跳过记录**：查看什么时候、在哪个 App、点了什么按钮、用了多久。带 📳 的表示广告页面上有「摇一摇」之类的提示。每条会标明是「通用兜底」还是「规则 xxx」。
- **设置**：
  - **通用关键词兜底**：对没有专属规则的 App，打开后 5 秒内自动点角落里的「跳过」。如果发现误点，可以关掉它，只使用专属规则。
  - **应用白名单**：加入白名单的 App 完全不处理。某个 App 被误点，或者你就是想看它的开屏，把它加进去。
  - **内置规则**：有专属规则的 App（目前是腾讯视频、爱奇艺），跳得更准、更快。

## 五、遇到没跳过或者点错的广告：抓快照发给我

我会根据快照给那个 App 写专门的规则。

1. 在主页打开 **「显示快照按钮」**。屏幕右边会出现一个半透明的 **📷** 按钮，所有 App 里都能看到，按住可以拖动。
2. **遇到开屏广告没被跳过时，趁广告还在，点一下 📷**。看到「已保存快照」的提示就成功了。来不及的话，退出那个 App 再打开一次。
3. 回到「定海神针」→ **「页面快照」**，找到刚才那条，点 **「分享」** → 发到微信给我。

说明：
- 广告被跳过了、但是**点错了地方**（比如点开了广告或会员页面），也请抓一份快照。就算抓到的不是广告页面也有用，快照里带着服务最近的运行日志。
- 快照包含当时屏幕上的文字和截图，只保存在你手机上，只有你主动分享才会发出去。分享前可以先看一眼。
- 不需要抓的时候，把「显示快照按钮」关掉即可，不影响跳过功能。

## 六、常见问题

- **有的 App 跳不过**：有些广告的跳过按钮是画出来的图片，或者位置、文字比较特殊，通用方式识别不了。请按第五节抓快照发给我。
- **跳过有时慢一两秒**：从 App 打开到广告真正显示出来需要时间，服务要等按钮出现后才能点。
- **重启手机后**：服务一般会自动恢复。如果主页显示没有在运行，到无障碍设置里重新开关一次。
- **不想用了**：到系统的无障碍设置里关掉「定海神针 · 开屏跳过」，然后正常卸载即可。
